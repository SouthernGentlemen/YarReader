# YarReader v1.0.1

Governance correction after public cutover: remove automated dependency
version-update pull requests because they cannot receive a permanent YR change
ID before creation and therefore fail the protected controlled-history checks.
The history validator also excludes GitHub's ephemeral pull-request merge head
while continuing to validate every real commit in the proposed history.

GitHub vulnerability alerts, private vulnerability reporting, secret scanning,
and push protection remain repository-level controls. Dependency version
updates are opened deliberately under an assigned YR ID.
